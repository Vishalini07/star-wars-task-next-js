# Star Wars Character Manager

This project is a **Next js + TypeScript** application that allows users to view, edit, and manage their favorite Star Wars characters using data from the SWAPI API. The UI is built with **Tailwind CSS**, and the project follows a modular approach with reusable components.

---

### **1️⃣ Clone the Repository**

git clone https://github.com/Vishalini07/star-wars-task-next-js.git
cd star-wars-task-next-js

### **1️⃣ Commands to run the project**

npm install

npm run dev

## **🚀 Features**
- **View Star Wars Characters**: Fetch and display character details.
- **Favorites Management**: Add or remove characters from favorites.
- **Edit Modal**: Modify character attributes (height & gender).
- **Pagination**: Navigate between character pages.
- **Reusable Components**:
  - `GenericButton`: A configurable button component.
  - `GenericCard`: A reusable Card in home page.
- **State Management**: Uses React hooks (`useState`, `useEffect`, `useContext`).
- **Type Safety**: Interfaces are used for defining API responses.
